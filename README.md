# Flappy Bird Clone (Pygame)

A simple Flappy Bird clone built using **Python** and **Pygame**.

## Features

* Bird movement with gravity
* Jump using **Space**, **W**, or **Up Arrow**
* Randomly generated pipes
* Score counter
* Collision detection
* Game Over screen
* Restart game after losing

## Technologies Used

* Python 3
* Pygame

## Concepts Used

* Object-Oriented Programming (Classes)
* Game Loop
* Timers (`pygame.USEREVENT`)
* Image Loading & Scaling

## Requirements

* Python 3.x
* Pygame

Install Pygame:

```bash
pip install pygame
```
